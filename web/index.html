01

PRIMARY MODE

Wardriver

Separate Wi-Fi, BLE and LoRa views. Time-stamped observations, available receiver GPS, raw radio evidence and versioned sessions on microSD.

  • 2.4 GHz Wi-Fi AP observations
  • Passive BLE advertisements
  • One fixed LoRa receive profile at a time
  • Start, Stop + Save, and offline export
02

EVIDENCE VIEW

Recon

Passive Wi-Fi/BLE matches, category filters and readable evidence grades. Bounded buzzer alerts and optional SD rules help you choose what matters.

  • Matched results, with evidence and confidence
  • iBeacon, Remote ID and supported signatures
  • Vendor/name matches stay candidates
  • LoRa reception stops in Recon

A signature is evidence, not proof of a product, recording activity or identity. Randomized BLE addresses are temporary. Recon captures no Bluetooth connections and transmits no LoRa packets.

03 / CONNECT & INSTALL

One supported kit.
One clear target.

Heltec WiFi LoRa 32 Expansion Kit V2, with the V4-R8 ESP32-S3 board and 915 MHz radio hardware.

Use desktop Chrome or Edge over HTTPS and a USB data cable. Close serial monitors and other flashers. The installer identifies the ESP32-S3 chip; it cannot identify the expansion board or antenna variant for you.

Official Heltec hardware ↗Verified pins and board details ↗Back up stock firmware and recover ↗

04 / FIRST SESSION

Card in. Mode selected.
Start observing.

  1. 1

    Prepare microSD

    Copy the supplied lora-tunnel folder to a FAT32 card. Rename config.example.json to config.json. The sample contains no credentials.

  2. 2

    Choose Wardriver

    Start Drive begins a local session. No GPS fix? Observations are still logged, with missing coordinates explicit.

  3. 3

    Stop + Save

    Wait for saving to finish before removing the card or powering off. Keep the native logs; export copies later.

WiGLE CSV export needs fresh valid GPS and UTC; observations without them remain in native logs. WDGWars mesh export additionally requires decoded, trustworthy node fields that this beta does not yet produce. Export rules ↗
